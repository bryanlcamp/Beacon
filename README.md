# BEACON // Bare-Metal HFT Asset Simulation Laboratory

BEACON is an uncompromised, low-latency execution simulation laboratory built entirely in **C++23 via template metaprogramming**. It discards legacy historical replay loops to synthesize reactive microstructure, multi-layered latency queues, and network transport volatility entirely on a local workstation.

---

### 🗂️ Core Infrastructure Architecture

| Generative Laboratory | Execution Fidelity | Risk Hardening Suite |
| :--- | :--- | :--- |
| ┃ **Six-Figure Feeds Not Needed.**<br>Cut out data infrastructure overhead. Save your firm from an expanding multi-terabyte cloud storage database bill on day one. | ┃ **The Expediter Queue Engine.**<br>Models explicit venue queue competition against Tier-1 firms using physical co-location skews and fiber line transit intervals. | ┃ **Transport-Layer Volatility.**<br>Subject your ingest logic to non-deterministic bursts, packet drop profiles, split binary frames, and out-of-order sequencing. |

| ┃ **Create the Data You Want.**<br>Instantly build multiple limit order books to evaluate real-time cross-asset arbitrage or fragmented venue tracking. | ┃ **Unencrypted C++23 Source.**<br>Distributed directly as an open, modular source package.
